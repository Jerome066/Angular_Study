ANGULAR

Componente: Pieza fundamental que representa una parte del UI, cada componente tiene: HTML, CSS y TypeScript
Interpolación: Utiliza la sintaxis de dobles llaves {{..}} para evaluar expresiones y renderizar el resultado de manera dinámica, se puede mostrar datos de propiedades del componente dentro de la plantilla de manera directa.
	Se puede:
		Mostrar datos: Puede mostrar valores de variables, propiedades del componente, o el resultado de una expresión directamente en la vista.
		Concatenación de cadenas.
		Evaluación de expresiones simples.



Componente en linea (inline): Se refiere específicamente a la forma en que el HTML y los estilos de ese componente son declarados. En lugar de vincular un archivo HTML externo mediante templateUri, el código HTML se escribe directamente dentro del archivo TypeScript utilizando comillas invertidas ` y la propiedad template

Ejemplo
import {Component} from '@angular/core';

@Component({
  selector: 'app-root', // Nombre del componente, así se llamara 
  template: `
	<h1>{{titulo}}</h1> (Atributo A)
	<p>{{descripcion}}</p> (Atributo B)
  `,
  styles: `
    :host {
      color: #a144eb;
    }
  `,
})
export class AppComponent {
	titulo = 'Componente Basico';
	descripción = 'Este es un componente simple en Angular'
}

NOTA: se recomienda como buena practica separar los atributos (HTML, CSS, TS) en sus respectivos archivos

Para crear un nuevo componente con Angular CLI

INTERPOLACIÓN


<section>
    <div class="container">
        <h2 class="text-center tex-warning">{{title}}</h2>
        <p>Bienvenido, {{usuario.nombre}}</p>
        <p>Edad: {{usuario.edad}}</p>
        <p>{{saludar()}}</p>
        <p>Dentro de poco tendras: {{usuario.edad + 1}}</p>
    </div>
</section>


@Component({
  selector: 'app-interpolacion',
  imports: [],
  templateUrl: './interpolacion.component.html',
  styleUrl: './interpolacion.component.css'
})
export class InterpolacionComponent {
  title = "Componente con interpolación";
  usuario = {
    nombre: 'Jorge',
    edad: 26
  };

  saludar(){
    return `Hola, ${this.usuario.nombre}`;
  }
}

ENCAPSULAMIENTO 

import { Component } from '@angular/core';

@Component({
  selector: 'app-encapsulamiento',
  imports: [],
  templateUrl: './encapsulamiento.component.html',
  styleUrl: './encapsulamiento.component.css'
})
export class EncapsulamientoComponent {
  private titulo = "Titulo encapsulamiento";

  get mostrarTitulo(){
    return this.titulo;
  }

  getTitulo(){
      return this.titulo
  }
}

|. {{ mostrarTitulo }}: Aquí estás accediendo al método get mostrarTitulo 
como si fuera una propiedad. No necesitas paréntesis porque el getter está diseñado 
para funcionar como una propiedad. 
2. {{ getTitulo() }}: Aquí estás llamando al método getTitulo() de forma 
explícita como un método de encapsulamiento, por lo que necesitas usar paréntesis.
